# QVAC Local AI

A simple local AI app using Tether's QVAC SDK to run a language model on-device.
QVAC SDK version: @qvac/sdk 0.19.1

## Requirements

- Node.js 22.17 or newer
- npm
- A computer that supports the QVAC runtime
